# Proyecto San Valentín

Este proyecto crea una página web interactiva para pedir ser San Valentín. La página contiene dos botones: "Sí" y "No", con interacciones interesantes para el botón "No".

## Estructura del proyecto

- `index.html`: Archivo principal que contiene la estructura de la página.
- `style.css`: Contiene los estilos CSS para dar formato a la página.
- `script.js`: Archivo de JavaScript que maneja la lógica de los botones.
- `assets/`: Carpeta que contiene imágenes utilizadas en la página.
- `README.md`: Este archivo, que describe el proyecto.
- `LICENSE`: Archivo de licencia MIT.

## Características

- **Interacción con el botón "No"**: 
  - Cambio de tamaño del botón "Sí".
  - Cambio de texto del botón "No" con 30 mensajes aleatorios.
  - Cambio de color del botón "No".
  - Cambio de posición del botón "No".
- **Mensaje de aceptación**: Al presionar el botón "Sí", se muestra un mensaje de aceptación junto con una imagen de amor.

## Cómo usar

1. Descarga o clona este repositorio.
2. Asegúrate de que todos los archivos (`index.html`, `style.css`, `script.js` y las imágenes en la carpeta `assets`) estén en el mismo directorio.
3. Abre `index.html` en tu navegador web preferido.
4. Interactúa con los botones y observa los cambios y mensajes.

## Personalización

Puedes personalizar varios aspectos del proyecto:

- **Modificar los mensajes**: Edita la lista `messages` en el archivo JavaScript (`script.js`) para cambiar los mensajes que muestra el botón "No".
- **Ajustar colores**: Edita la lista `colors` en el archivo JavaScript (`script.js`) para cambiar los colores aleatorios del botón "No".
- **Cambiar posiciones**: Edita la lista `positions` en el archivo JavaScript (`script.js`) para cambiar las posiciones aleatorias del botón "No".
- **Actualizar imágenes**: Sustituye las imágenes en la carpeta `assets` por otras imágenes que desees mostrar.
