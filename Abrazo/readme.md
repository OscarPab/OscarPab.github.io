# Abrazo Virtual

Este proyecto es una página web interactiva que envía un abrazo virtual. Al completar la animación de carga, aparecen corazones y rosas flotando para acompañar el mensaje "Abrazo enviado!".

## Estructura del proyecto

- `index.html`: Archivo principal que contiene la estructura de la página.
- `styles.css`: Contiene los estilos CSS para dar formato a la página.
- `penguin.svg`: Imagen utilizada en la página.
- `README.md`: Este archivo, que describe el proyecto.

## Características

- **Animación de carga**: Una barra de carga animada que simula el envío del abrazo virtual.
- **Corazones y rosas flotantes**: Al completar la animación de carga, aparecen corazones y rosas flotando en diferentes posiciones de la pantalla.
- **Fondo color rosa pálido**: La página tiene un fondo de color rosa pálido para una apariencia amigable.

## Cómo usar

1. Descarga o clona este repositorio.
2. Abre `index.html` en tu navegador web preferido.
3. Observa cómo se carga la página y disfruta del abrazo virtual acompañado de corazones y rosas flotantes.

## Personalización

Puedes personalizar varios aspectos del proyecto:

- **Cambiar la imagen**: Sustituye `penguin.svg` por cualquier otra imagen que desees mostrar.
- **Modificar los colores**: Cambia los colores en el archivo CSS (`styles.css`) según tus preferencias.
- **Ajustar el número de corazones y rosas**: Modifica el número de elementos en la sección de JavaScript dentro de `index.html`.
