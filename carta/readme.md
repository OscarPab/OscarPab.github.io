# Carta Interactiva de San Valentín

Este proyecto crea una página web interactiva para enviar una carta de San Valentín. La página contiene dos botones: "Abrir" y "Cerrar", con una carta que se despliega como un pop-up para mostrar el mensaje completo.

## Estructura del proyecto

- `index.html`: Archivo principal que contiene la estructura de la página.
- `style.css`: Contiene los estilos CSS para dar formato a la página.
- `script.js`: Archivo de JavaScript que maneja la lógica de la carta.
- `assets/`: Carpeta que contiene imágenes utilizadas en la página.
- `README.md`: Este archivo, que describe el proyecto.
- `LICENSE`: Archivo de licencia MIT.

## Características

- **Interacción con la carta**:
  - La carta muestra un mensaje parcial con las primeras 20 palabras.
  - Al presionar el botón "Abrir", la carta se despliega como un pop-up y muestra el mensaje completo.
  - Al presionar el botón "Cerrar", la carta se cierra y vuelve a su estado original.
- **Diseño atractivo**: La carta tiene un diseño visualmente atractivo con animaciones suaves.

## Cómo usar

1. Descarga o clona este repositorio.
2. Asegúrate de que todos los archivos (`index.html`, `style.css`, `script.js` y las imágenes en la carpeta `assets`) estén en el mismo directorio.
3. Abre `index.html` en tu navegador web preferido.
4. Interactúa con los botones "Abrir" y "Cerrar" para desplegar y cerrar la carta.

## Personalización

Puedes personalizar varios aspectos del proyecto:

- **Modificar el mensaje**: Edita el contenido del mensaje en el archivo HTML (`index.html`) para cambiar el mensaje que muestra la carta.
- **Actualizar estilos**: Edita el archivo CSS (`style.css`) para cambiar el diseño y los estilos de la carta y los botones.
- **Actualizar imágenes**: Sustituye las imágenes en la carpeta `assets` por otras imágenes que desees mostrar.
